From now on, treat this project as a modern Search Growth project, not as traditional SEO only.

The operating framework is:

SEO + AEO + GEO + SXO + Entity SEO + Visual/Multimodal Search + Conversion Optimization

The business objective is not “more indexed pages” or “more impressions.” The objective is:

Search Visibility → Answer/AI Visibility → Qualified Traffic → Trust → Lead / Sale / Order

## 1. Protect what already works

Before creating or changing anything, audit the current website.

Do not rebuild healthy structures.
Do not create duplicate pages.
Do not create pages merely for keyword variations.
Do not cause keyword cannibalization.
Do not change layout, design, navigation, URLs, or working functionality unless there is a verified SEO/UX reason and the change is explicitly safe.

Never invent:
- customers
- projects
- reviews
- rankings
- prices
- statistics
- percentages
- test results
- case studies
- business achievements

Existing evidence is more valuable than fabricated “SEO content.”

## 2. Follow current Google Search principles

Use current Google Search documentation as the primary reference.

Modern SEO must prioritize:

- People-first content
- Search intent
- First-hand experience
- Original research
- Original analysis
- Non-commodity information
- Real evidence
- Clear authorship
- Trust
- Technical accessibility
- Page experience
- Entity clarity
- Useful images and video
- Internal linking
- Conversion experience

Do not chase SEO myths.

Do not treat llms.txt as a Google ranking tactic.
Do not create FAQ sections merely to obtain FAQ rich results.
Do not change article dates without meaningful content updates.
Do not create hundreds of AI-generated long-tail pages.
Do not keyword-stuff pages.
Do not write to arbitrary word counts.

## 3. Build non-commodity content

Before publishing an article, ask:

“What does this page contain that cannot be reproduced by simply asking an AI model the same question?”

Whenever possible, include:

- first-hand observations
- actual project experience
- original screenshots
- original photographs
- measurements
- real tests
- real Search Console data
- real comparisons
- methodology
- limitations
- original tools/calculators
- original datasets
- expert interpretation

Prefer:

“We audited 12 real category pages and found X in 7 of them.”

over:

“7 common SEO mistakes.”

Every number or percentage must have a real source or documented methodology.

## 5. Create original research

Turn the business's actual operations into content.

Examples:

- audit real websites
- analyze real products
- compare real category structures
- analyze real Search Console queries
- test real pages
- document real projects
- analyze real customer questions
- publish anonymized aggregate findings when appropriate

Create research articles and case studies from this evidence.

Use a repeatable structure:

Research Question
Methodology
Sample
Measurements
Findings
Evidence
Interpretation
Limitations
Recommendations

Never predetermine that a website/product/page is “good” or “bad.” Let evidence determine the findings.

## 6. Treat interactive tools as content

Calculators, diagnostic tools, configurators, filters, comparison tools and useful interactive features can be valuable main content.

If the business can solve part of the user's problem before asking for a sale, build or improve the tool.

Make useful tools prominent enough to be discovered quickly.

Connect:

Tool → Result → Explanation → Relevant service/product → CTA

## 7. Manage existing content scientifically

Do not automatically delete pages with low traffic.

Classify pages using Search Console and business value:

High impressions + low CTR
→ improve title/snippet/intent alignment.

Positions roughly 5–20
→ strengthen content, evidence, internal links and relevance.

Traffic exists but information is outdated
→ meaningful refresh.

Two pages satisfy the same intent
→ evaluate consolidation/canonical/301.

Zero impressions + thin content + no unique intent
→ rewrite, merge or remove.

Zero impressions but strategically valuable topic
→ investigate indexability, internal links, content quality and demand before deleting.

Low-value obsolete page with no useful replacement
→ consider removal.

Content pruning is evidence-based, not automatic.

## 9. Optimize for AI/Generative Search without gimmicks

Do not treat GEO/AEO as hacks.

Strong AI visibility starts with strong SEO.

Make pages easy to understand and extract:

Clear entities
Clear relationships
Direct answers
Descriptive headings
Concise factual passages
Original evidence
Reliable citations
Structured data that matches visible content
Consistent organization/person/service/product information

Cover meaningful subquestions naturally rather than generating one page for every possible query.

## 10. Optimize for visual and multimodal search

Images are search assets.

For important original images:

- use high-quality originals
- use descriptive filenames
- write accurate alt text
- provide meaningful surrounding text
- associate the image with the correct entity/product/project
- use appropriate image metadata/schema where relevant
- avoid decorative duplication
- keep important images crawlable

Monitor Search Console multimodal search data where available, including Lens, Circle to Search, image uploads and Search-this-image discovery.

Make the site's important entities unambiguous:

Organization
People
Products
Services

Connect these consistently across pages and structured data.

Prefer genuine third-party mentions, citations, partnerships, PR and references over manufactured backlinks or fake mentions.

## 14. Internal linking must follow user intent

Do not add links merely to manipulate PageRank.

Build logical paths such as:

Research → Guide → Category/Product/Service
Article → Tool
Tool → Commercial Page
Case Study → Relevant Service
Product → Category
Category → Buying Guide
Guide → Relevant Products

Use descriptive anchors naturally.

## 15. Optimize for conversion, not traffic alone

SEO ends at business outcome, not ranking.

Evaluate:

Can users understand the offer quickly?
Is proof visible?
Is the next action obvious?
Is mobile usable?
Are CTAs appropriate to intent?
Can users compare options?
Can they contact/order/request a quote easily?
Are trust signals genuine?

Measure where possible:

Qualified organic traffic
Organic leads/orders
Landing-page conversion
Query → landing page alignment
CTR
Engagement
AI visibility
Multimodal visibility

## 16. Refresh based on evidence

Create a recurring content refresh system.

Use Search Console to identify:

Rising queries
Declining pages
New query clusters
Pages near page-one positions
High-impression/low-CTR pages
Cannibalization
AI feature visibility
Multimodal visibility

Update pages when there is a real reason.

Document material updates.

## 17. AI content rule

AI may assist research, organization, analysis, drafting and editing.

AI must not be used to mass-produce commodity pages.

Every important AI-assisted page should gain human/business-specific value through:

Evidence
Experience
Original analysis
Data
Examples
Images
Tools
Methodology
Expert review

## 18. Execution rule

Do not stop because one tool is unavailable.

Use the best available alternative source or tool.

Before each major change:

Audit → Decide → Execute → Test → Measure.

Work in batches and report briefly:

1. What was checked
2. What was found
3. What was changed
4. Why it matters
5. What should be measured next

The final standard is:

Less commodity content.
More evidence.
More experience.
More original data.
Better intent matching.
Better technical clarity.
Better visual search readiness.
Better internal relationships.
Better user experience.
More qualified business outcomes.
